# Día 3: Diseño de interfaz

## Menú, consultar disponibilidad y estadísticas

**Hecho por:** Luis Eduardo Mendoza Romero

Así se van a ver las pantallas del programa. Después de cada pantalla se regresa al menú.

---

### Menú principal

```text
========== CINE ==========
1. Mostrar sala
2. Reservar asiento
3. Liberar asiento
4. Consultar disponibilidad
5. Ver estadísticas
6. Salir
==========================
Elige una opción:
```

### Consultar disponibilidad

```text
--- CONSULTAR DISPONIBILIDAD ---
Fila (A a E): D
Asiento (1 a 8): 2

El asiento está: Ocupado
```

### Ver estadísticas

```text
--- ESTADÍSTICAS ---
Ocupados: 2
Disponibles: 38
Porcentaje de ocupación: 5 %
```

### Salir

```text
Gracias por usar el sistema.
```

### Si se escribe algo que no existe

```text
Dato no válido, intenta de nuevo.
```
