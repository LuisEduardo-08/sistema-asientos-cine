## ¿De qué trata?

Un cine desea digitalizar el proceso de administración de asientos para evitar
errores en las reservaciones. Los asientos estarán organizados mediante una
matriz.

Nuestro programa ayuda a llevar ese control. La sala tiene 5 filas (de la A a la E) con 8 asientos
cada una, en total 40 lugares. Cada asiento aparece como **L** si está libre o como **X** si ya
está ocupado.

## ¿Qué se puede hacer con el programa?

- Ver cómo está la sala.
- Reservar un asiento.
- Liberar un asiento (por ejemplo, si alguien cancela).
- Revisar si un asiento está libre u ocupado.
- Saber cuántos asientos están ocupados y cuántos libres.
- Ver qué porcentaje de la sala está lleno.
